# Agente de IA do Instagram + Painel (Vercel)

Agente independente do AtendeFlow: responde DMs do Instagram com IA, dá
boas-vindas a novos leads, responde comentários dos posts (público + Direct) e
tem um painel com a movimentação, a captação de leads e as configurações, no
visual da Confianza Technologies.

**Instalação, configuração, uso e solução de problemas:
[MANUAL_TECNICO.md](MANUAL_TECNICO.md).**

```bash
npm install && npm test   # testes
vercel --prod             # publicar
```
